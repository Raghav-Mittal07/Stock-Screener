# Stock Screener

Stock screener built with FastAPI, React and MySQL.

## Setup
1. Install MySQL and create the database: CREATE DATABASE stock_screener;
2. Import the data: mysql -u root -p stock_screener < stock_screener.sql
3. Copy .env.example to .env and fill in your MySQL details
4. Backend: cd backend, pip install -r requirements.txt, then start FastAPI
5. Frontend: cd frontend, npm install, then npm start
